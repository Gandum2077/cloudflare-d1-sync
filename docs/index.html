1 您需要先了解

本项目用 Cloudflare Worker 和 D1 在多台设备间同步数据库。

用量限制：D1 免费版每日读取 500 万行、写入 10 万行；单库 500 MB、账户共 5 GB。实际额度以 Cloudflare 官方说明为准。


操作步骤：

  1. 生成密钥：在下方生成主密钥 MASTER_KEY 并复制。
  2. 开始部署：点击 Deploy to Cloudflare，进入 Cloudflare Worker 创建页面。
  3. 填写信息：您需要把主密钥填入部署表单的 MASTER_KEY 选项；至于其他选项，您可以自行决定。
  4. 部署之后：您需要保存主密钥和 Cloudflare worker 网址。
